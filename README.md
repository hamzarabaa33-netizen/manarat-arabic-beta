# المنارة — واجهة تجريبية V0.7

هذه نسخة **عامة تجريبية** من محرر المذكرات البيداغوجية، مستضافة عبر GitHub Pages.

- تعمل الواجهة والمحرر والنماذج المتاحة، مع حفظ بيانات المسودات في **متصفح الجهاز المستخدم**، والتصدير المحلي وفق إمكانات المتصفح.
- محرك استخراج DOCX/PDF، ومكتبة المؤسس على الخادم، والتوليد بالذكاء الاصطناعي **غير منشورة هنا**؛ تتطلب خدمة خلفية خاصة منفصلة ومصادقة مناسبة.
- لا ترفع بيانات حساسة أو ملفات تلاميذ إلى خدمات غير موثوقة.
- وجود هذه الواجهة على GitHub Pages **لا يعني أنها محمية أو محصورة بصاحب الحساب**. أي شخص لديه الرابط يمكنه الاطلاع على الموقع والكود العام. البيانات التي يحفظها زائر في متصفحه لا تُنشر تلقائيًا إلى المستودع.
- جميع المذكرات والنماذج تعليمية تجريبية، ولا يُدّعى اعتمادها وزاريًا.

النسخة الخاصة ذات الخادم ليست منشورة في هذا المستودع العام. يحتفظ مشروع المنارة الكامل بها بصورة منفصلة.
