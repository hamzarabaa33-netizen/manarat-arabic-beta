# منارة الاختبارات V0.23 — تفعيل محرك الذكاء الاصطناعي الآمن

**الحالة الحالية:** مصدر الخادم \`api/worker.mjs\` موجود في GitHub، ولم يُنشر إلى حساب Cloudflare بعد، ولا تتوافر مفاتيح OpenAI أو Cloudflare من هذا المشروع. لذلك سيعرض زر «إنشاء اختبار بالذكاء الاصطناعي» رسالة إعداد إلى أن تكتمل الخطوات الآتية.

## لماذا خادم مستقل؟

GitHub Pages ينشر ملفات HTML/JavaScript للجميع. كتابة \`OPENAI_API_KEY\` في صفحة عامة أو استدعاء API مباشرة من المتصفح يعرّض المفتاح للسرقة والفوترة غير المصرح بها. نستخدم Cloudflare Worker بوصفه واجهة خلفية: يقرأ المفاتيح من أسرار الحساب لا من مستودع GitHub العام.

## تفعيل الخدمة على حساب صاحب المشروع

1. أنشئ حساب Cloudflare أو استخدم حسابك ثم ثبّت Node.js / Wrangler إن لم يكن مثبتًا.
2. انسخ المستودع محليًا، ومن مجلد \`api\` شغّل:
   \`\`\`bash
   npx wrangler login
   npx wrangler deploy
   npx wrangler secret put OPENAI_API_KEY
   npx wrangler secret put TEACHER_ACCESS_TOKEN
   \`\`\`
3. عند أمر \`OPENAI_API_KEY\` ألصق **مفتاح API خاص بحساب OpenAI API**؛ اشتراك ChatGPT Plus لا يشمل رصيد API تلقائيًا. عند \`TEACHER_ACCESS_TOKEN\` اختر رمز دخول قويًا فريدًا (لا تستخدم كلمة مرور حساب ChatGPT أو GitHub).
4. افتح رابط Worker الذي سيظهر بعد النشر، على شاكلة \`https://manara-ai-exams.<حسابك>.workers.dev/health\`. يجب أن تعود استجابة \`configured: true\`.
5. افتح [منارة الاختبارات V0.23](https://hamzarabaa33-netizen.github.io/manarat-arabic-beta/exam-lab-v023.html). افتح «إعداد ربط الخادم الذكي»، أدخل الرابط **دون \`/health\`** ورمز دخول الأستاذ، ثم اضغط «اختبار الاتصال» و«إنشاء اختبار بالذكاء الاصطناعي».

**لا ترسل رمز الدخول أو المفتاح السري في المحادثة.** رموز الخادم لا تُحفظ في \`localStorage\`؛ يعاد إدخالها عند إعادة فتح المتصفح، بينما يُحفظ عنوان الخادم والموارد المدروسة محليًا.

## ما الذي ينفذه المحرك بعد التفعيل؟

- يستقبل نص السند المختار (ضمن حد حجمه) والمستوى والمقطع والنمط والموارد التي يؤكد الأستاذ أنه درّسها فعلًا.
- يولد أسئلة فهم تتعلق بأحداث السند، مع شاهد حرفي وإجابة متوقعة ومستوى بلوم مبرر.
- لا يولد أسئلة لغة إذا لم يحدد الأستاذ موارد مدروسة فعلًا، ويستبعد أي سؤال يستشهد بعبارة **غير موجودة حرفيًا** في السند.
- يجري طلب تدقيق إضافي مستقل من نموذج الذكاء الاصطناعي، ويرجع ملاحظات تدقيق ظاهرة للأستاذ.
- يبني ورقة قابلة للتحرير في المحرر الحالي، ويتيح إرسال النسخة المحررة إلى صفحة A4 بتنسيق Paged.js (إن حمّلت المكتبة بنجاح) مع بديل طباعة المتصفح.

**الحدود الجوهرية:** تطابق نص الشاهد **لا يثبت صحة الإعراب أو البلاغة أو الإجابة**. ولا يثبت المدقق وحده سريان مخطط الوزارة لعام 2018 في عام 2026، أو اعتماد شبكة تنقيط رسمية، أو وجود الترخيص بإعادة نشر النص. يجب مراجعة المعلم قبل اعتماد أو مشاركة الاختبار.

## خصوصية وتكاليف وأمان

- لا تُرسل أسماء التلاميذ أو بياناتهم الشخصية. نصوص السندات والموارد فقط تُرسل إلى نموذج API خارجي عند الضغط على زر الإنشاء.
- \`store:false\` ضمن طلب OpenAI Responses API، لكن تعامل مع بياناتك بحسب سياسة مزود الخدمة؛ لا تضع بيانات سرية.
- كل توليد قد يحتاج **طلبين مدفوعين من API** (التوليد والتدقيق). اضبط حد الإنفاق/الفوترة في حسابك وأضف قواعد Cloudflare WAF / Rate Limiting قبل إتاحتها للجمهور.
- يتطلب Worker رمز دخول للخدمة في كل طلب، ويسمح للموقع الأصلي فقط بـCORS، لكن **CORS وحده ليس نظام حماية من استدعاءات غير المتصفح**. يجب المحافظة على الرمز، وعدم نشره أو وضعه داخل الشيفرة.
- لا يُسمح للخدمة بأن تصبح متاحة لمستخدمين آخرين دون نظام هوية وترخيص حصيف مع حد لكل مستخدم.
- توجيهات منهجية مختصرة مضمنة في الخدمة؛ **لم ندرّب نموذجًا جديدًا على الكتب ولا استخرجنا جميع المناهج في قاعدة معرفة متجهية بعد**.
